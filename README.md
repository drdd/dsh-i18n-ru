# Русский язык для интерфейса DeepSeek Harness.

Пакет одновременно **бандл профиля** (вставляет свою строку в дерево) и
**клиентский плагин** (регистрирует язык и словари через штатный сервис
`locale`). `app.asar` не правится.

## Что делает

- Добавляет в каталог языков пункт **«Русский»** (`addLanguage({id:"ru",
  label:"Русский", fallback:"en"})`).
- Регистрирует русские словари по namespace (`ctx.locale.register(ns,
  {ru: {...}})`).
- Непереведённые ключи остаются английскими (fallback `ru → en`), интерфейс не
  ломается.
- Не навязывает язык: пока пользователь сам не выберет «Русский», активный язык
  не меняется.

## Установка

Штатно — через CLI (профиль `desktop`):

```
dsh plugin --profile desktop add {ПУТЬ}\dsh-i18n-ru
```

или через GUI: «Плагины → Добавить плагин → Установить сторонний плагин» и
указать абсолютный путь к папке пакета.

После установки **перезапустить DSH**, затем «Настройки → Общие → Язык →
Русский». Выбор сохраняется в пользовательских настройках
(`services.locale.preference: "ru"`).

## Удаление

```
dsh plugin --profile desktop remove dsh-i18n-ru
```

Затем перезапуск. Пункт «Русский» исчезает, язык возвращается к прежнему.

## Структура

```
package.json          манифест (dsh.bundle + dsh.client)
cordis.patch.yml      вставка строки i18n-ru в дерево профиля
lib/index.js          хост-заглушка (пакет виден загрузчику)
lib/client.js         СГЕНЕРИРОВАННЫЙ бандл: DICT_RU + apply
locale/{en,ru,zh}.json  метаданные для списка плагинов
src/inventory.json    снимок извлечённых en/zh словарей (62 namespace)
src/dict/<ns>.ru.json русские словари по namespace
src/validate.mjs      общая проверка словарей
src/build.mjs         проверка + генерация lib/client.js
src/verify.mjs        проверка + синтаксис бандла + покрытие
src/smoke.mjs         прогон бандла в фейковом ctx
```

## Сборка и проверка

```
node src/build.mjs     # валидирует словари и пишет lib/client.js
node src/verify.mjs    # полнота, плейсхолдеры, синтаксис, покрытие
node src/smoke.mjs     # addLanguage + register в фейковом ctx
```

`build` падает, если:

- набор ключей `ru` не совпадает с `en` в namespace;
- множества плейсхолдеров `{...}` не совпадают;
- есть пустые строки.

## Как добавить перевод

1. Открыть `src/dict/<ns>.ru.json` (или создать файл для нового namespace).
2. Перевести значения, **сохранив плейсхолдеры** (`{count}`, `{name}`,
   `{seconds}` и т.п.) дословно.
3. `node src/build.mjs && node src/verify.mjs`.
4. Перезапустить DSH (или дождаться перезагрузки клиента).

## Обновление после новой версии DSH

Новые ключи автоматически показываются по-английски. Чтобы перевести разницу:

1. Пере-извлечь инвентарь (скрипты в `dsh-i18n-ru\tools\`):
   - `node dsh-i18n-ru/tools/extract.mjs` — распаковать клиентские пакеты из `app.asar`;
   - `node dsh-i18n-ru/tools/extract-dicts.mjs` — собрать `dsh-i18n-ru/work/inventory.json`.
2. Скопировать `dsh-i18n-ru/work/inventory.json` в `dsh-i18n-ru/src/inventory.json`.
3. `node dsh-i18n-ru/src/verify.mjs` покажет непереведённые namespace/ключи.
4. Перевести разницу, собрать, проверить.
